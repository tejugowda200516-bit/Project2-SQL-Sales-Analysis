# SQL Sales Analysis

## Project Overview
This project analyzes sales data using SQL to identify useful business insights.

## Dataset
- File: SQL_sales_Dataset_200_Rows.csv
- Contains sales records for analysis.

## Analysis Performed
- Total Revenue
- Total Quantity Sold by Product
- Revenue by Region
- Revenue by Product Category

## Tools Used
- SQL
- CSV Dataset

## Project Objective
To practice SQL queries and understand sales performance across products, regions, and categories.
